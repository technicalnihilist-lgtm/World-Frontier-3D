## Reference research — Wikimedia Commons

These photographs were collected through the Commons API (`generator=search` with `imageinfo/extmetadata`) and studied as visual references for architecture, vehicles, terrain, weather and wildlife. **No Commons image is redistributed inside the game** — every texture and model is generated in code. Each entry records the creator and licence reported by the API at the time of research; the file page carries the authoritative licence text and attribution requirements.
